## Pre-Generation Data Queries

Run these before generating the summary text:

```bash
# Top 3 callers for the period
python3 /path/to/call-tracker/query_calls.py --leaderboard --min-calls 1

# Calls logged during coverage window
python3 /path/to/call-tracker/query_calls.py --hours [hours_in_window]

# Generate sentiment overlay chart
# Monday post (3-day window):
python3 /path/to/call-tracker/chart_generator.py --days 3 --output /tmp/community_chart.png --title "Fri-Sun"
# Friday post (4-day window):
python3 /path/to/call-tracker/chart_generator.py --days 4 --output /tmp/community_chart.png --title "Mon-Thu"
```

For active streaks and ticker consensus, query calls.db directly:
```sql
-- Active hot streaks (streak_count >= 3 on most recent closed call per member)
SELECT username, streak_count, ticker, result_final
FROM calls
WHERE status = 'closed'
  AND (member_id, timestamp) IN (
    SELECT member_id, MAX(timestamp) FROM calls WHERE status='closed' GROUP BY member_id
  )
  AND streak_count >= 3
ORDER BY streak_count DESC;

-- Ticker consensus for coverage window
SELECT ticker, direction, COUNT(DISTINCT member_id) as members, AVG(price_at_call) as avg_entry
FROM calls
WHERE timestamp >= [window_start_ts]
GROUP BY ticker, direction
HAVING members >= 3
ORDER BY members DESC;
```

## Summary Structure (Section Order)

Omit conditional sections if no qualifying data exists. Never include empty sections.

### 1. Header
```
📊 Community Summary — [Weekend Wrap: Fri–Sun | Week-in-Review: Mon–Thu]
[Date range, e.g. "May 9–11, 2026"]
```

### 2. Top 3 Themes
The three most discussed topics across all 4 channels during the coverage window.
Keep each theme to 1-2 sentences. Factual, signal-based. No fluff.

### 3. Sentiment Score
```
💬 Community Sentiment: [score]/100 ([+X vs last summary | -X vs last summary])
[One-line interpretation, e.g. "Cautious but constructive — BTC indecision dominating."]
```

### 4. Sentiment Overlay Chart
Attach the PNG generated by chart_generator.py. Caption: "Community Sentiment vs BTC, SPY, NASDAQ"

### 5. Community Consensus (CONDITIONAL — only if 3+ members same ticker/direction)
```
📡 Community Consensus
[TICKER] — [N] members [bullish/bearish] (entry avg: $[price])
[TICKER] — [N] members [bullish/bearish] (entry avg: $[price])
```
For bearish: label as "Community Fade" for that ticker.
Omit section entirely if no ticker hit 3+ threshold.

### 6. Hot Streak (CONDITIONAL — only if active streak >= 3 exists)
```
🔥 Hot Streak
[username] — [N] wins in a row (last: [TICKER] [+pnl%])
```
Omit section entirely if no active streaks.

### 7. Member Calls
All calls logged during the coverage window. Group by ticker.
```
📈 Member Calls ([N] logged)
[TICKER]: [username] (bullish @ $[price]) | [username] (bearish @ $[price])
```
If no calls: omit section.

### 8. Fact-Checked Claims
Top 3-5 specific factual claims made in the channels during the window.
Verify each against a live API before including.

**Sourcing rules:**
- Price/asset claims → Polygon (stocks/ETFs) or CoinMarketCap/CoinGecko (crypto)
- News/macro claims → NewsAPI or NewsData.io
- Unverifiable → mark as [Source: unverified]
- No links — source tag only

Format:
```
🔍 Fact Check
"[Claim as stated]" — [CONFIRMED/UNCONFIRMED] [Source: X]
```

### 9. Top 3 Callers (for the coverage period)
```
🏆 Top Callers
1. [username] — [win_pct]% ([W]W/[L]L)
2. [username] — [win_pct]% ([W]W/[L]L)
3. [username] — [win_pct]% ([W]W/[L]L)
`/leaderboard` for full rankings
```
If fewer than 3 qualify (min 1 closed call for this section), show however many exist.
Omit if zero.

### 10. Most Accurate Caller
```
🎯 Most Accurate Caller
[username] — [win_pct]% ([W]W/[L]L) | Best call: [TICKER] [+pnl%]
```
Pull rank #1 from the leaderboard. Omit if no qualifying callers.

## Tone and Style

- Signal over noise. Every sentence earns its place.
- No em dashes (—). Use commas, periods, or restructure.
- No hedging language ("may", "might", "could suggest").
- Fact-check claims before including. If unverifiable, omit or tag [Source: unverified].
- Treat members as sophisticated investors. No over-explanation.
